راهنمای نصب روی هاست (میهن وب‌هاست و هاست‌های مشابه)
==========================================================

این بسته یک سرور کامل است: صفحه‌های برنامه + پایگاه داده‌ی خودش (بدون Supabase).
فایل‌ها: app.cjs (کل سرور در یک فایل) و پوشه‌ی dist (صفحه‌ها). نیازی به «npm install» نیست.

پیش‌نیاز هاست
-------------
هاست باید «Node.js» داشته باشد (در cPanel منوی «Setup Node.js App» یا «Node.js Selector»؛ در DirectAdmin
گزینه‌ی مشابه). نسخه‌ی Node ۱۸ یا بالاتر کافی است. هاستی که فقط PHP یا Python دارد نمی‌تواند این بسته را اجرا کند.
(اگر فقط PHP/Python دارید، از حالت Supabase استفاده کنید: فقط پوشه‌ی dist را آپلود کنید.)

مراحل نصب در cPanel (اسم دکمه‌ها ممکن است کمی فرق کند)
-----------------------------------------------------
۱. «Setup Node.js App» ← «Create Application»
   - Node.js version: بالاترین نسخه‌ای که هست (۱۸ یا بالاتر)
   - Application mode: Production
   - Application root: مثلاً  wpc   (پوشه‌ای در خانه‌ی هاست، نه داخل public_html)
   - Application URL: دامنه یا زیردامنه‌ای که می‌خواهید برنامه روی آن باز شود
   - Application startup file: app.cjs
۲. با «File Manager» به پوشه‌ی wpc بروید، فایل wpc-host.zip را آپلود و «Extract» کنید.
   بعد از باز کردن، فایل app.cjs و پوشه‌ی dist باید مستقیم داخل wpc باشند (نه داخل یک پوشه‌ی دیگر).
۳. در همان صفحه‌ی برنامه، در بخش «Environment variables» این‌ها را اضافه کنید:
   - ADMIN_PASSWORD = یک رمز قوی برای اولین ادمین (حداقل ۸ نویسه)
   - DATA_DIR = /home/نام‌کاربری‌شما/wpc-data   (اختیاری ولی توصیه می‌شود: داده بیرون از پوشه‌ی برنامه بماند)
   متغیر PORT را نگذارید؛ خود هاست آن را مدیریت می‌کند.
۴. دکمه‌ی «Restart» (یا Start) را بزنید و دامنه را باز کنید.
۵. SSL رایگان (AutoSSL / Let's Encrypt) را برای دامنه فعال کنید و با https باز کنید.
   (روی http برنامه کار می‌کند ولی نصب روی گوشی و امنیت ورود به https نیاز دارد.)
۶. با نام کاربری  admin  و همان ADMIN_PASSWORD وارد شوید.

انتقال اطلاعات از سایت قبلی (Supabase)
-------------------------------------
۱. در سایت قبلی با ادمین وارد شوید ← تب «پشتیبان‌گیری» ← «دانلود فایل پشتیبان».
   این فایل همه چیز دارد: قیمت‌ها، فرمول‌ها، محصولات، هزینه‌ها، انبار، پارت‌ها و محصول ساخته‌شده.
۲. در سایت جدید با ادمین وارد شوید ← تب «پشتیبان‌گیری» ← کادر «بازگردانی کامل» ← انتخاب فایل ← تأیید.
   قبل از جایگزین شدن، خودکار یک فایل پشتیبان از وضعیت فعلی سایت جدید دانلود می‌شود.
۳. کاربرها منتقل نمی‌شوند (رمزها قابل انتقال نیست). در تب «کاربران» دوباره بسازید و به هر کس نقشش را بدهید
   (ادمین، اپراتور یا مشاهده‌گر).

پشتیبان‌گیری
------------
- هر چند روز یک بار از تب «پشتیبان‌گیری» فایل پشتیبان بگیرید و جای امنی نگه دارید.
- تمام داده در یک فایل است: DATA_DIR/baravord.sqlite (اگر DATA_DIR نگذاشته‌اید: پوشه‌ی data کنار app.cjs).
  از آن هم در پشتیبان‌گیری هاست نسخه بگیرید. هنگام کپی، برنامه می‌تواند روشن باشد.

به‌روزرسانی
-----------
بسته‌ی جدید را آپلود کنید و فقط app.cjs و پوشه‌ی dist را جایگزین کنید. پوشه‌ی data را دست نزنید
(داده‌ها آنجاست). بعد «Restart» بزنید.

نکته‌های مهم
-----------
- فقط یک نمونه از برنامه باید روشن باشد. اگر هاست گزینه‌ی تعداد پروسه یا Instances دارد، روی ۱ بگذارید.
- روی Node ۲۲٫۵ یا بالاتر، برنامه خودش از پایگاه داده‌ی داخلی Node استفاده می‌کند؛ روی نسخه‌های قدیمی‌تر از یک
  پایگاه داده‌ی جاوااسکریپتی داخل همین فایل استفاده می‌شود (هر دو یک فایل داده می‌سازند و نیاز به نصب چیزی نیست).
  اگر خواستید حالت دوم را اجباری کنید: متغیر WPC_DB=sqljs
- اگر صفحه خطای ۵۰۳ می‌دهد، برنامه شروع نشده: در صفحه‌ی برنامه گزارش خطا (log) را ببینید؛
  معمولاً Application root یا Startup file اشتباه است (باید app.cjs باشد).
- اگر ADMIN_PASSWORD نگذاشته باشید، رمز اولیه‌ی تصادفی فقط یک بار در گزارش (log) برنامه چاپ می‌شود.
